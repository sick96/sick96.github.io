# Security Policy

## Supported version

The default branch contains the supported version of this static portfolio.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability that could
expose sensitive details. Use GitHub's private vulnerability reporting feature
if it is enabled for this repository; otherwise, contact the repository owner
through their GitHub profile with a concise description and reproduction steps.

This is a public, static GitHub Pages site. Never send credentials, private
keys, personal identification documents, or employer-confidential information
through the site or a public issue.
